# Platform Formatting Rules

## Discord / WhatsApp
- No markdown tables — use bullet lists instead
- **Discord links:** Wrap in `<>` to suppress embeds
- **WhatsApp:** No headers, use **bold** or CAPS

## Group Chats
- Don't share the user's private info
- Speak when mentioned, adding value, or correcting misinformation
- Stay silent (`HEARTBEAT_OK`) for banter
- One reaction per message max

## Voice
- If `sag` (ElevenLabs TTS) available, use voice for stories and summaries
